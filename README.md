# Tanakh Game — прототип

Прототип 2D-игры с видом сверху на [Phaser 3](https://phaser.io/) (чистый JavaScript, без сборщика).
Графика — цветные квадраты-плейсхолдеры.

- **Движение:** WASD или стрелки
- **Атака:** пробел (бьёт всех врагов в радиусе вокруг игрока)
- **I** — инвентарь (игра на паузе)
- **R** — начать заново после победы или поражения

Враг идёт за игроком (обходя стены), при касании наносит урон. Полоска здоровья и текущая
экипировка — в левом верхнем углу. На карте лежат предметы: оружие увеличивает урон, броня
уменьшает получаемый урон.

## Запуск

### Локально

Проще всего поднять любой статический сервер в корне репозитория:

```bash
python3 -m http.server 8000
# или
npx serve .
```

и открыть <http://localhost:8000>.

Скрипты подключены обычными `<script>` (не ES-модулями), поэтому `index.html` можно открыть и
двойным кликом прямо из папки. Нужен интернет: Phaser загружается с CDN jsDelivr.

### GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch.**
3. Выберите ветку (например, `main`) и папку `/ (root)`, нажмите **Save**.
4. Через минуту игра будет доступна по адресу `https://<user>.github.io/<repo>/`.

Все пути в проекте относительные, а файл `.nojekyll` отключает обработку Jekyll, так что
дополнительная настройка не нужна.

## Структура

```
index.html                 — страница, подключает Phaser и скрипты по порядку
src/
  config.js                — все настройки: размеры, цвета, игрок, типы врагов, слоты и предметы
  maps.js                  — карты (строковые сетки)
  main.js                  — создание Phaser.Game
  scenes/GameScene.js      — сцена: сборка карты, коллизии, атака, подбор предметов, HUD, победа/поражение
  scenes/InventoryScene.js — экран инвентаря (I), запускается поверх игры
  entities/Player.js       — игрок: движение, атака, здоровье, экипировка
  entities/Enemy.js        — враг: преследование, получение урона, смерть
  entities/Item.js         — предмет на карте
  systems/Equipment.js     — слоты экипировки, сумка, подсчёт бонусов
  ui/HealthBar.js          — полоска здоровья
  utils/pathfinding.js     — поиск пути по тайлам (BFS) для врагов
```

Объекты общаются через события сцены: `player-attack`, `player-hp-changed`, `equipment-changed`,
`player-dead`, `enemy-dead`.

## Как добавить новую карту

Карты лежат в `src/maps.js`. Каждый символ строки — один тайл 32×32:

| Символ | Значение |
|--------|----------|
| `#`    | стена |
| `.`    | пол |
| `P`    | старт игрока (ровно один) |
| `E`    | враг типа `chaser` |
| `s` `x` `l` `c` | предметы: ржавый меч, боевой топор, кожаная броня, кольчуга |
| другой | символ врага из `CONFIG.ENEMY_TYPES` или предмета из `CONFIG.ITEMS` |

1. Добавьте новую запись в объект `MAPS` (все строки — одинаковой длины):

   ```js
   const MAPS = {
     level1: { ... },
     arena: {
       name: 'Арена',
       tiles: [
         '####################',
         '#..................#',
         '#..P...........E...#',
         '#......####........#',
         '#..........E.......#',
         '####################',
       ],
     },
   };
   ```

2. Откройте карту:
   - временно — через URL: `index.html?map=arena` (работает и на GitHub Pages);
   - по умолчанию — поменяйте `START_MAP: 'arena'` в `src/config.js`.

Размер мира и границы камеры считаются из размеров карты автоматически.

## Как добавить нового врага

Типы врагов описаны в `CONFIG.ENEMY_TYPES` (`src/config.js`). Для простого врага
(другая скорость, здоровье, урон, цвет) код писать не нужно:

1. Добавьте тип с уникальным символом:

   ```js
   ENEMY_TYPES: {
     chaser: { ... },
     runner: {
       symbol: 'R',      // символ на карте
       size: 18,         // размер квадрата в пикселях
       color: 0xd08770,  // цвет плейсхолдера
       speed: 150,
       hp: 1,            // сколько ударов выдерживает (урон игрока = attackDamage)
       damage: 10,       // урон игроку при касании
       aggroRange: 300,  // с какого расстояния начинает преследовать
     },
   },
   ```

2. Поставьте `R` на карту в `src/maps.js`.

Текстура `enemy-<ключ>` создаётся автоматически в `GameScene.createTextures()`.

**Если нужно другое поведение** (стрельба, патруль и т. п.), создайте подкласс `Enemy`
и зарегистрируйте его:

```js
// src/entities/Shooter.js
class Shooter extends Enemy {
  update(time, target) {
    super.update(time, target);
    // своя логика...
  }
}
ENEMY_CLASSES.Shooter = Shooter;
```

Подключите файл в `index.html` **после** `Enemy.js` и укажите класс в типе врага:
`shooter: { symbol: 'S', class: 'Shooter', ... }`. Без поля `class` используется базовый `Enemy`.

## Экипировка и предметы

У игрока два слота — **оружие** и **броня** (`CONFIG.EQUIPMENT_SLOTS`), плюс сумка без ограничения размера.

- Подобранный предмет надевается сразу, если его слот пуст; иначе попадает в сумку.
- В инвентаре (**I**): ↑/↓ или W/S — выбор, **Enter** или **E** — надеть предмет из сумки
  (надетый ранее уходит в сумку) или снять предмет со слота. **I** или **Esc** — закрыть.
- Урон атаки = `PLAYER.attackDamage` + `damage` оружия.
- Получаемый урон = урон врага − `defense` брони, но не меньше 1.

При рестарте (R) экипировка сбрасывается.

### Как добавить предмет

1. Добавьте запись в `CONFIG.ITEMS` (`src/config.js`):

   ```js
   ITEMS: {
     // ...
     war_hammer: {
       symbol: 'h',        // символ на карте (уникальный, не занятый стенами/врагами)
       name: 'Боевой молот',
       slot: 'weapon',     // ключ из EQUIPMENT_SLOTS
       damage: 3,          // бонус к урону (для оружия)
       // defense: 0,      // бонус к защите (для брони)
       color: 0xb48ead,    // цвет квадрата-плейсхолдера
     },
   },
   ```

2. Поставьте `h` на карту в `src/maps.js`.

Текстура `item-<ключ>` создаётся автоматически.

### Как добавить слот

Добавьте ключ в `CONFIG.EQUIPMENT_SLOTS` (например, `ring: 'Кольцо'`) и укажите `slot: 'ring'`
у нужных предметов. Инвентарь и HUD подхватят слот сами. Бонусы (`damage`, `defense`)
суммируются по всем слотам; новую характеристику можно прочитать через
`player.equipment.bonus('<имя поля>')`.

## Замена плейсхолдеров на спрайты

Добавьте в `GameScene` метод `preload()` с `this.load.image('player', 'assets/player.png')` и т. д.
и уберите соответствующие вызовы `makeRectTexture` — ключи текстур (`player`, `wall`,
`floorA`, `floorB`, `enemy-<тип>`, `item-<предмет>`) останутся прежними. `makeRectTexture` не перезаписывает
уже загруженные текстуры.

## Отладка

`DEBUG: true` в `src/config.js` включает отображение хитбоксов Arcade Physics.
